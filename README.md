# Контент-фабрика «Сентябрь» — генератор ВК-постов

**МVP финального проекта курса по Claude Code.**

Двухшаговый мини-сервис для создания постов ВКонтакте в голосах маскотов ИСЦ «Сентябрь»: сначала контент-аудит тематики, затем генерация поста с учётом рекомендаций.

---

## 🎯 Проблема

Командам и экспертам, которые ведут несколько площадок ВКонтакте, приходится каждый раз:

- искать ракурс для поста;
- помнить, как говорит каждый персонаж;
- не смешивать голоса и не забывать перекрёстные ссылки;
- держать в голове LSI-термины и успешные форматы.

Это рутина, которую можно автоматизировать.

## 👤 Для кого

- SMM-менеджерам и контент-менеджерам;
- маркетологам, работающим с бренд-персонажами;
- экспертам и методистам, которые ведут несколько аккаунтов;
- студентам и начинающим продюсерам контента.

## ⚙️ Основная функция

1. **Аудит тематики**: пользователь вводит нишу, аудиторию и продукт. Сервис возвращает рекомендуемые темы, LSI-термины, форматы, угол повествования и пробел в контенте.
2. **Выбор маскота**: Алиса, Арчи (Ардальон), Полина или Надежда Андреевна.
3. **Генерация поста**: на основе выбранной темы и LSI-терминов сервис создаёт пост в правильном голосе с хештегами и перекрёстными ссылками (для Алисы и Арчи).

## 📦 Формат результата

- Готовый текст поста для ВКонтакте;
- Подобранные хештеги;
- Указание длины без пробелов;
- Информация о том, какие LSI-термины вошли в текст.

## ✅ Минимальный функционал (MVP)

- [x] Форма аудита тематики;
- [x] Рекомендации по темам, LSI, форматам и углу;
- [x] Четыре голоса маскотов с разными стилями;
- [x] Генерация поста с хештегами;
- [x] Перекрёстные ссылки для Алисы и Арчи;
- [x] Кнопка копирования результата;
- [x] Адаптивный веб-интерфейс.

**В планах:** подключение внешнего LLM для более гибкой генерации, интеграция с настоящим контент-планом и сохранение истории постов.

## 🛠 Технологии

- **Python 3.11+**
- **Flask 3.0.3** — веб-фреймворк
- **HTML5 + CSS3** — интерфейс
- ** vanilla JavaScript** — логика фронтенда

Без внешних CDN, без npm, без сборщиков. MVP работает локально в одной папке.

## 🚀 Как запустить

1. Склонируй репозиторий:
   ```bash
   git clone https://github.com/RNA124/september-content-mvp.git
   cd september-content-mvp
   ```

2. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запусти приложение:
   ```bash
   python app.py
   ```

4. Открой в браузере:
   ```
   http://127.0.0.1:5000
   ```
