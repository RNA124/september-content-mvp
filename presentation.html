Контент-фабрика «Сентябрь»

Генератор ВК-постов с аудитом тематики и голосами маскотов: Алиса, Арчи, Полина и Надежда Андреевна.

Python + Flask Маркетинг / SMM MVP
Проблема

Зачем этот проект?

Когда ведёшь несколько площадок ВКонтакте от имени разных персонажей, каждый пост приходится собирать вручную: думать над темой, не смешивать голоса, помнить про перекрёстные ссылки и LSI-термины. Это рутина, которую можно упростить.

Курс по Claude Code задаётся вопросом: «какую реальную задачу я могу автоматизировать?». Мой ответ — ручная подготовка постов для бренд-персонажей.

Решение

Как работает сервис

1. Аудит тематики
темы, LSI, форматы
→
2. Выбор маскота
4 голоса
→
3. Генерация поста
готовый текст + хештеги
«Сначала аудит, потом план, потом пост» — именно так устроен реальный конвейер в проекте.

Результаты

Что получается на выходе

01

Готовый пост

В правильном голосе маскота, с хештегами и перекрёстными ссылками.

02

Рекомендации по теме

Темы, LSI-термины, форматы, угол и пробел в контенте.

03

Проверка длины

Выводится длина поста без пробелов — важно для ВКонтакте.

04

Копирование в один клик

Пост можно сразу скопировать и вставить в редактор ВК.

GitHub

Репозиторий и технологии

Стек: Python 3.11+, Flask 3.0.3, HTML5/CSS3, vanilla JavaScript.

Структура: Flask-приложение, модуль аудита, шаблоны и стили в одной папке. Без npm и сборщиков — MVP работает локально.

README оформлен по структуре курса: проблема, пользователь, функция, формат результата, минимальный функционал, технологии, запуск.

Планы

Что дальше?

  • Подключить внешний LLM для более гибкой генерации постов.
  • Добавить сохранение истории аудитов и постов в файл или базу.
  • Сделать экспорт готовых постов в Markdown или CSV.
  • Расширить аудит: интеграция с анализом конкурентов и семантикой.

Самое ценное в проекте — не генератор текста, а сам конвейер: аудит → план → пост. Именно он решает реальную рутинную задачу.
