# Скилл: Контент-фабрика «Сентябрь» MVP

## Назначение

Этот скилл помогает Claude Code работать с репозиторием генератора ВК-постов для ИСЦ «Сентябрь». Он описывает структуру, правила запуска, доработки и публикации проекта.

## Структура репозитория

```
september-content-mvp/
├── app.py              # Flask-приложение: роуты /, /audit, /generate
├── auditor.py          # Логика мини-аудита тематики
├── requirements.txt    # Flask==3.0.3
├── README.md           # Описание проекта для GitHub
├── .gitignore          # Исключения для git
├── .claude/
│   └── SKILL.md        # Этот файл
├── static/
│   └── style.css       # Стили интерфейса
└── templates/
    └── index.html      # Главная страница приложения
```

## Что делает приложение

1. **/audit** — получает на вход `{niche, audience, product}` и возвращает рекомендации по темам, LSI-терминам, форматам, углу и пробелу в контенте.
2. **/generate** — получает `{mascot, topic, lsi_terms}` и возвращает готовый пост в голосе выбранного маскота.
3. **/** — отдаёт HTML-интерфейс, где пользователь проходит весь конвейер.

## Правила изменений

- **Не добавляй внешние CDN, Google Fonts, аналитику, виджеты.** Всё должно работать локально.
- **Сохраняй голоса маскотов**, определённые в `app.py` (`MASCOTS`).
- **LSI-термины из аудита должны автоматически вплетаться в пост** (минимум 2 термина).
- **Перекрёстные ссылки** ставятся только для Алисы и Арчи, как в реальном проекте.
- **Не выкладывай внутренние промпты и агентов** из рабочей директории `D:\Загрузки\Проект`. Этот репозиторий — только публичная MVP-версия.

## Как запустить

```bash
pip install -r requirements.txt
python app.py
```

Открыть: http://127.0.0.1:5000

## Как добавить нового маскота

1. Добавь запись в словарь `MASCOTS` в `app.py`.
2. Укажи `name`, `platform`, `role`, `tone`, `style_note`, `emoji_pool`, `hashtags`, `link_to` (если нужны перекрёстные ссылки) и `templates`.
3. В шаблонах используй переменные: `{topic}`, `{emoji}`, `{lsi1}`, `{lsi2}`, `{link}`.
4. Добавь иконку в `templates/index.html` в блоке `{% if key == ... %}`.

## Как обновить README

README оформлен по структуре курса: название, проблема, пользователь, функция, формат результата, минимальный функционал, технологии, инструкция по запуску, скриншоты, скилл, ссылка. При изменении функционала обновляй соответствующие разделы.

## Как подготовить к публикации

1. Проверь локальный запуск.
2. Сделай скриншоты интерфейса и положи в папку `images/`.
3. Обнови раздел «Скриншоты» в README, добавив ссылки `![описание](images/имя_файла.png)`.
4. Убедись, что `.claude/SKILL.md` актуален.
5. Сделай коммит и пуш в репозиторий RNA124/september-content-mvp.
